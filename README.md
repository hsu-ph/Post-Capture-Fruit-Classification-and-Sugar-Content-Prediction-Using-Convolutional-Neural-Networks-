# Senior-Project

## Project Overview

To address the growing health concerns caused by low fruit consumption and high intake of sugary beverages, this project proposes a smart dietary recommendation system focused on fruits. Despite government guidelines encouraging at least two daily servings of fruit, over 86% of individuals aged 19–64 fall short (Ministry of Health and Welfare, 2018). The system leverages facial emotion recognition, fruit image analysis, and personal activity data to offer real-time, personalized fruit recommendations. The goal is to replace sugar-sweetened beverages with healthy, homemade fruit teas and promote long-term dietary improvement through intelligent behavior guidance.


## Key Features

1. **Emotion-Based Recommendations**: Using facial emotion analysis, the system evaluates users' moods and past nutritional intake to recommend fruits that support both mental and physical well-being.
2. **AI-Powered Fruit Recognition**: Through machine learning and computer vision, users can photograph fruits to estimate ripeness, sweetness, and nutritional value, enabling intuitive and accurate food tracking.
3. **Personalized Nutrition Planning**: Based on user profiles (age, sex, activity level), the system calculates daily caloric and sugar needs, translating them into fruit serving recommendations aligned with national dietary guidelines.

The system is implemented using a full-stack architecture including React Native, Azure Cloud Services (Cognitive Services, Custom Vision, Cosmos DB), and LINE Bot SDK, enabling seamless user interaction, data processing, and real-time deployment. A context diagram, video demonstration, and nutrition sources are integrated to support user accessibility, government outreach, and business extension.
